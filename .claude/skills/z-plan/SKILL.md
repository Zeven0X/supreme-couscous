# Plan — agree on the route before driving

## Steps
1. If key facts are still missing, ask instead of guessing: the HARD rule 1 layout, "ok" = ⭐ answers.
2. Write the plan:
   - **Goal** (1 line)
   - **Steps** — numbered, ≤ 8, each small enough to check
   - **Files/outputs** that will be created or changed
   - **How we'll verify** it works (tests, run command, preview, checklist)
   - **Risks** — top 1–3 things that could go wrong
3. If there are two sensible approaches, show both in a small table (effort, quality, risk) and recommend one.
4. Ask: **"Go with this plan? (yes / change X)"** and wait.

## Feedback
Point out anything in the request that looks over-scoped, under-specified, or likely to cause rework.
