ABOUT THE MOD
-------------
- Genesis Forge is my custom NeoForge mod in CurseForge modpack instance 5423.
- Minecraft 1.21.1, NeoForge 21.1.262, Java 21. Jar: genesisforge-1.0.0.jar (~26.8 MB, must stay under 30 MB).
- Main parts: Genesis Forge block + soul orbs, 4 spawner tiers, Soul Balls, Abyssal storage, Block Drill,
  Omni Nexus (9-tab station, enchants up to high levels), Galaxium gear (tier above Netherite),
  8 Galaxium mini-bosses, 13 apple trees, many enchantment reworks.
- Enchant max levels (Omni Nexus): normal gear = 10x the vanilla max, Galaxium gear = 50x (was capped at 255).

3. TREE BONE MEAL CHANGE (DECIDED, NOT BUILT)
---------------------------------------------
Giant 2x2 tree = exactly 8x, mega 3x3 tree = exactly 24x the average bone meal ONE sapling of that type needs.
Fixed count, not random. One sapling average = round(2 x slowness / 0.45).

Tree                        1 sapling   Giant 2x2   Mega 3x3
Apple                           9           72         216
Iron                           13          104         312
Golden / Emerald / Diamond     22          176         528
Netherite                      44          352       1,056
Galaxium                      111          888       2,664
Enchanted trees: same rule, using each tier's own growth slowness.

6. ENCHANTMENT REWORKS (DECIDED, NOT BUILT)
-------------------------------------------
SMITE
- Every hit on ANY mob heals the attacker 0.005 HP per level.
- Keeps the vanilla extra damage against undead (+2.5 per level).
- Normal max 50 = 0.25 HP | Galaxium 250 = 1.25 HP | 100x set 500 = 2.5 HP.

KNOCKBACK
- +0.05 blocks of reach per level, for attacking AND breaking/placing blocks.
- Still pushes mobs back like vanilla.
- Adds on top of the Galaxium tools' +75% reach.
- Normal max 20 = +1 block | Galaxium 100 = +5 blocks | 100x set 200 = +10 blocks.

AQUA AFFINITY
- Helmet only.
- While fully underwater: takes 0.75% per level off the damage that is left AFTER all other damage reduction.
- Keeps the vanilla faster mining underwater.
- Normal max 10 = 7.5% | Galaxium 50 = 37.5% | 100x set 100 = 75%.
- Example: 100 damage -> 80% armor -> 20 left -> Aqua Affinity 75% -> 5 damage taken (95% total).
