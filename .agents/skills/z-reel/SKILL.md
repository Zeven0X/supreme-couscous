# Reel — script + caption package

## 1. Check the brief
If there is no brief yet, ask the `z-brief` first group of questions (HARD rule 1 layout).

## 2. Write the package
**Hook options (3)** — first 1–2 seconds, on-screen text ≤ 7 words. Mark the recommended one ⭐.

**Shot list**
| # | Time | Visual | On-screen text | Audio/SFX |
|---|---|---|---|---|
| 1 | 0–2s | Hook shot | | |
| … | | | | |
| n | last 2s | CTA | | |

Keep total 7–20s unless asked otherwise. Before/after reveal at the midpoint or via a swipe/slider transition works best for restoration.

**Caption** — first line is a hook; 2–4 short lines; one clear CTA (e.g. "DM 'RESTORE' to fix your old photos").

**Hashtags** — 5–10, mix of niche and broad. No banned or irrelevant tags.

**Cover frame** — which frame and what text.

## 3. Feedback
- Rate the hook strength (1–5) honestly and say why.
- One idea to make it more shareable.
- Ask: "Want a second version in a different tone?"

## Rules
- Text must be readable on a phone: large, high contrast, inside safe zones (avoid the top 14% and bottom 20% of the 9:16 frame).
- Don't use copyrighted music lyrics in captions or on-screen text.
