# Ship — finish properly

## Checklist (run each, report ✅ / ❌)
1. **Requirements**: re-read the original request/brief. Every point met?
2. **Works**: run it / open it / play it end to end.
3. **Clean**: remove debug prints, temp files, commented-out junk, secrets.
4. **Docs**: `PROJECT.md` index and topic pages are up to date — every element listed, removed ones ❌ with reason, "How to run it" and "Where we stopped" correct, web pages rebuilt.
5. **Files**: correct names, formats, sizes (e.g. 1080×1920 for Reels, under upload limits).
6. **Backup**: committed to git or saved in a safe folder.

## Output
- The checklist with results.
- Anything ❌ → fix it or ask.
- Then the full feedback block (use the `z-feedback` skill).
