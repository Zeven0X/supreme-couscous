# Idea shaper — help find what the user means

The user often has a feeling, not a spec. Turn the feeling into something clear, one small step at a time.

## 1. Catch the spark
Repeat back the one thing you're sure of, in their words:
"You want a boss that feels **scary**. Let's figure out the rest together."

## 2. Show, don't ask
Give **2–3 concrete versions** they can picture. Use games they likely know, and describe how each **feels to play** in 1–2 sentences:

```markdown
**1- Which is closest to your idea?**

A1- Like Minecraft's Wither — *big flier, shoots exploding skulls* ⭐

B1- Like a Zelda dungeon boss — *find its weak spot*

C1- Like a horror chase — *run and hide, then fight back*

D1- Mix of these

E1- Other:

---

✍️ Reply like **A1** — or **ok** for the ⭐ answer
```

- Options must be really different from each other, not small variations.
- "Mix" is allowed: "A1's look with C1's chase" → build on that.
- Here each option may add a short italic description after a dash, on the same line (this is the only place options get one).
- "Other" or "none of these" → ask what felt wrong about each, then offer 3 new versions.

## 3. Narrow down with tiny choices
After they pick, ask about **one detail at a time** (size, speed, look, sound, reward), always in the HARD rule 1 layout with one ⭐.

## 4. Help with words
If they struggle to describe something:
- Offer **feeling words**: a question like **How should it feel?** with Scary · Funny · Epic · Other:
- Ask for a **reference**: **Is there a game or video with this vibe?** with Yes, I'll name it · No ⭐ · Other:
- Ask what it should **not** be: **What would ruin it?** with Too easy · Too long · Too random · Other:
- For looks, describe or sketch with simple shapes/colors and ask "closer or further?"

## 5. Play it back
Write a short summary card and check it:

```
## 💡 The idea so far
- What: <one line>
- Feels like: <one line>
- How it works: <2–3 simple bullets>
- First small version: <the tiny thing we'd build first>

---

**1- Is this your idea?**

A1- Yes, build it ⭐

B1- Close, but change something

C1- Start over

D1- Other:

---

✍️ Reply like **A1** — or **ok** for the ⭐ answer
```

## 6. Handle "I don't know"
- It's a valid answer. Pick the ⭐ option, give one line of why, and say "we can change this anytime".
- If they're stuck on many things, suggest building a **tiny test version** so they can feel it in-game and decide from there.

## Rules
- Never make the user feel bad for not knowing.
- Never fill gaps silently. Every guess you make is shown to them as a ⭐ choice.
- Save the final idea card to the right topic page in `PROJECT.md` / `docs\` before building.
